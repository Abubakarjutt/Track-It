# v1.1 Cluster 7g-2 — Per-muscle-group stimulus metrics — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking. One vertical slice per TDD cycle; run `swift test` every cycle.

**Goal:** Answer "how many working sets did I do for *chest* this week" — a
per-muscle-group **set volume** (CONTEXT.md "Set volume", the training-stimulus
gauge distinct from Volume / tonnage). 7g-1 already shipped the per-exercise and
per-workout set-volume rollups in Core; 7g-2 adds the muscle-group dimension,
App-side, with **Core frozen**.

**Architecture:** A `MuscleGroup` enum (the 11-group hypertrophy taxonomy,
`CaseIterable`) + a `MuscleMap` lookup (exercise **name** → `[MuscleGroup]`,
seeded from the 6 built-in starters) + a `MuscleGroupSetVolume` result
(`perGroup: [MuscleGroup: Int]` + `unclassified: Int` + a reconciling `total`).
The fold `MuscleMap.setVolume(across:in:)` reuses Core's
`workoutSetVolumeByExercise(_:)` (warmups excluded, supersets count per entry,
timed/distance sets count) and attributes each exercise's working-set count
**flat 1.0** to every group its name maps to. A `calendarWeek(containing:in:)`
helper (Monday start) gives the window. A `MuscleGroupStimulusModel`
(`@Observable`, `@MainActor`) reads `store.history()` and exposes this week's
volume; `MuscleGroupStimulusView` (in `App/`, files-only) draws the weekly
per-group bar + an "unclassified" row.

**Tech Stack:** Swift 6, Swift Testing (`import Testing`, `#expect`), SwiftData,
SwiftUI (iOS 17+). Package work in `Packages/WorkoutLoggerApp`
(`swift test --no-parallel` — the parallel runner deadlocks this package);
`App/` is not compiled here.

**Spec:** `docs/superpowers/specs/2026-09-11-cluster-7g-stimulus-metrics.md`
(7g-2) — all 8 open questions **resolved 2026-09-12**. Parent:
`2026-09-06-v1.1-deferred-work-design.md` § "Cluster 7". Branch:
`v1.1-clusters-6-7d-7g1` (7g-1 already on it).

## Global Constraints

- **No `WorkoutLoggerCore` changes.** 7g-2 is App-side by decision (Q1 = c).
  Before every commit, `git diff --stat Packages/WorkoutLoggerCore` must be
  empty. The fold *reuses* Core's `workoutSetVolumeByExercise(_:)`; it does not
  add to Core.
- **Strict TDD:** red → green → refactor, one vertical slice per cycle.
- **Flat attribution (Q4):** a working set's count adds to *every* group its
  exercise maps to. No primary/secondary weight.
- **Unclassified reconciles (Q5):** an exercise the map doesn't know adds its
  working-set count to `unclassified`. Invariant:
  `total == perGroup.values.sum + unclassified`, and
  `total == Σ workoutSetVolume(w) for w in window`.
- **Monday-start calendar week (Q6):** a workout belongs to the week its
  `startedAt` falls in; `calendarWeek` uses `firstWeekday = .monday`.
- **Export deferred (Q8):** do not add per-group counts to
  `WorkoutHistoryExport`.
- **`App/` is not compiled here.** App files match the package API exactly and
  are reviewed by read-through.
- Baseline: **Core 169 / App 245** (post-7g-1). State the new App count per
  commit.
- Commit after every green step, conventional-commit style
  (`feat(progress): …`, `test(progress): …`, `refactor(progress): …`,
   `docs(7g): …`).

   `feat(progress): add MuscleGroup + MuscleMap lookup (cluster 7g-2)`.

### Task 2 — `MuscleGroupSetVolume` + `setVolume(across:in:)` fold (red→green)
- [ ] Red: flat attribution — a bench (chest+triceps+shoulders) week with 3
      working sets puts 3 in each of those three groups; total 9.
- [ ] Red: unclassified — an exercise with no mapping lands in `unclassified`;
      `total == Σ perGroup + unclassified`; and `total == Σ workoutSetVolume(w)`
      over the window (the reconciliation invariant).
- [ ] Red: windowing — a workout outside the `DateInterval` is ignored; a workout
       straddling the boundary is owned by its `startedAt` week.
- [ ] Red: warmups excluded; a timed/distance working set still counts; a
       2-exercise superset round counts as its entries (inherited from
       `workoutSetVolumeByExercise`).
- [ ] Green: `MuscleGroupSetVolume(perGroup:unclassified:)` + `total`;
      `MuscleMap.setVolume(across:in:)` reuses `workoutSetVolumeByExercise(_:)`
       and attributes flat 1.0.
- [ ] Run `swift test --no-parallel`. Commit
   `feat(progress): fold per-muscle-group set volume (cluster 7g-2)`.
